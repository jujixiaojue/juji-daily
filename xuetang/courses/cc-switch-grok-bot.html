CC Switch 接不进这套 Grok Bot

CC Switch 是给 Claude Code、Codex、Gemini CLI、Grok Build 管配置和自定义 API 的工具。这套 Grok Bot 应用没有对外的 OpenAI / Anthropic 兼容 API，不能当成后端接上去。

1. CC Switch 是什么

CC Switch（farion1231/cc-switch，网站 ccswitch.io）给几种编程助手命令行工具管配置、提供商和路由，面向 Claude Code、Codex、Gemini CLI、Grok Build。

2. 自定义提供商与计费

可以加自定义提供商：填 URL、API Key、模型 ID；如果接口格式不是原生 Responses，还可以做本地路由转换。有官方 xAI（Grok）预设。Grok Build 会写入 ~/.grok/config.toml。自定义站点的 API 由那个站点计费；xAI API Key 不是 Grok Bot 的登录凭证。

3. 为什么接不进 Grok Bot

这套 Grok Bot 应用是聊天与任务入口，不是对外的 OpenAI 或 Anthropic 兼容 API 服务。CC Switch 不能把本应用当成后端挂上去。
