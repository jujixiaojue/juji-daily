Hermes Agent：飞书与微信的会话记忆为什么不能互通

部署在阿里云的 Hermes，持久记忆工具可共用，但飞书和微信是两套独立会话历史。AgentMsgr 也拼不起这两个窗口的内部记忆。

产品调研 技术方案
整理日期：2026-11-19（UTC+8）
资料范围：Nous Research Hermes Agent 仓库、阿里云官方部署说明，以及 GitHub issues #25544、#4335。未改部署配置。

1. 导读

Hermes Agent 可通过 Gateway 接飞书、微信（Weixin / iLink）、企业微信和钉钉，阿里云也提供一键部署。常见误会是同一个 Hermes 实例接了两个渠道，记忆就一定共享。官方和已知 issue 都说明：不是这样。

2. 会话键按平台分开

会话键按平台分开，例如 agent:main:weixin:dm:xxx 与 agent:main:feishu:dm:xxx。持久记忆工具可以共享，但会话历史本身不共享。微信里讲过的要求，飞书窗口里看不到原对话。

3. AgentMsgr 不能把两个窗口拼起来

它连的是「一个 Hermes 助手」，最多多出一个共享房间。不会把微信和飞书的内部会话史缝起来。

4. 实用做法

换渠道时把关键要求再说一遍，或把截图发到当前窗口。真正要长期共用的约定，写进 Hermes 的持久记忆，而不要只留在某一侧的聊天记录里。
