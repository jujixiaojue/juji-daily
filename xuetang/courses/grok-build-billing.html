Grok Build 与 Grok Bot 是不是同一套用量

在当前 Cursor Pro+ 上，两者分账计量。SuperGrok 周限额不覆盖 Grok Bot；若后来换成 The X Subscription，Grok、Grok Bot 和 Cursor 会共用一个周池，但凭证仍不可互换。

1. 名字都带 Grok，账不一定在同一个池子

Grok Build 是 xAI 的编程命令行工具 grok。Grok Bot 是 Cursor / xAI 提供的主动式助手应用。名字都带 Grok，但账不一定在同一个池子里。

2. 当前 Cursor Pro+

Grok Build 走 Grok / SuperGrok 的周限额池（Chat、Build、Voice 等），在 Grok 设置的 Usage 里看。Grok Bot 的用量记在 Cursor 账户上，与 SuperGrok 分开计。官方 FAQ 明确：两套表分开，Weekly SuperGrok Limit 不管 Grok Bot。On-demand 可同时覆盖 Grok Bot 和 Cursor。凭证不能互换。

3. 若后来改用 The X Subscription

若后来改用 The X Subscription，Grok、Grok Bot 和 Cursor 会共用一个周池。那仍然不是同一把 API Key。
