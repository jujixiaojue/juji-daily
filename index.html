🤖 AI Agent 前沿洞察

Google 威胁情报组：首次记录到可无人值守完成「补丁到利用」的 Agent 框架

11 月 16 日，Google Threat Intelligence Group（GTIG）与 Mandiant 发布季度更新，题为「Agentic Threat Activity Crosses a Significant Threshold」。官方称，过去一个季度里，他们首次发现威胁行为者使用大模型框架，在没有人介入的情况下，自动完成漏洞发现与利用。

报告写到，该框架出现在一台暴露的预发布服务器上，可对接多个前沿模型与本地模型，并被设置为持续比较常用 Web 应用在补丁公告前后的代码差异，分析可能漏洞，起草利用代码并自动执行。Google 同时在该服务器上看到失窃数据，以及用于内网侦察、暴力破解、安装或清理 webshell 的脚本；受害者遥测显示，运营者对法国媒体、娱乐和教育类网站更感兴趣。

SiliconANGLE 对同日报告的转述补充：Google 没有指认该框架已成功利用的某个具体漏洞，也没有给出受害者数量或「补丁到利用」的实测耗时，因此不宜把「发现框架」写成「已大规模得手」。官方建议仍是缩短补丁落地时间，并核对来源，而不是相信来路不明的概念验证。本文只记录公开结论，不转述技术细节。

来源：Google Cloud / GTIG 博客（2026-11-16）；SiliconANGLE 同日报道

科学发现 Agent：英伟达把开源模型、化学数据与后训练配方打包给实验室

同一天，英伟达在新闻稿中发布 Nemotron for Science：以开源视觉语言模型 Nemotron 3.5 Super VL 为基础，配上新的开放化学数据集 LitmusBench v0.2（约 5 万道化学推理题）和后训练配方，帮助研究机构构建领域科学 Agent。新闻稿列举的使用方包括 Lila Sciences、Terray Therapeutics、Therna，以及美国能源部阿贡国家实验室、于利希超算中心等。这是工具与评测资源发布，不是新的上市药物或人体试验结果。细节见「AI 制药」板块。

来源：NVIDIA 新闻稿（2026-11-16）

未来方向洞察：今日几条线索指向同一趋势——Agent 正在从「辅助写代码、辅助问答」进入可连续执行的工作流，评测也从单次答题转向「模型 + harness」的真实仓库与终端任务（见第 7 节 Coding Agent Index v2.1）。与此同时，攻击侧同样把补丁差分、利用起草和执行串成无人值守流水线，补丁披露后的窗口会被进一步压缩。对做 Agent / 本体中台的团队，这意味着两件事同时变硬：一是要把技能、评测和来源核验做成可治理的平台能力（今日 GitHub 日榜上 SkillEvaluator、AG-UI、代码审查工具的热度也在印证这一点）；二是不能把未签发、来路不明的 Agent 输出直接当成可执行事实。

🔗 Ontology（本体）生态动态

本板块同时出现两类「Ontology / 本体」，含义不同，下文分开写，避免张冠李戴。

一、企业知识本体 / 本体中台

Palantir 在 11 月 12 日的 Foundry 公告中宣布，Ontology SQL 与 SQL 函数已正式可用（GA），并写明该能力自 11 月 9 日当周起在全部 enrollment 上开放。官方说明：Ontology SQL 可用 Spark SQL 方言的一个子集查询已发布的对象类型、接口和多对多链接；查询先走对象存储上的内存计算路径，更复杂的查询再自动转到 Spark。SQL 函数是可参数化、可发布的 Ontology 查询，能在 Workshop、Actions、Automate 和 Ontology SDK 中复用。配套的 SQL Studio 用于编写和运行这些查询，并可把查询发布为函数、在 Ontology Manager 中管理版本。

同月稍早（11 月 10 日），Palantir 还宣布 SuperRepo 预览支持 REMOTE_ONLY 模式：可在本地对已有 Ontology 中的实况对象和链接做只读预览，而不再依赖手工维护的种子数据。访问仍走用户自身权限，对象类型 schema 不一致时会报错并停止返回数据。

补充背景（非今日新事件）：Databricks 已于 11 月 11 日将 Genie Ontology 推至正式可用，定位为「由 Agent 构建、由人治理、供每个 Agent 使用」的企业级本体。若与 Palantir 对照：前者更强调由 Agent 抽取片段、由人签发权威口径再分发；后者更强调对已发布对象、接口和链接的 SQL 查询与可版本化函数。两者都把「未发布或互相冲突的口径不能直接拿来算」当成治理问题，只是切入点不同。

来源：Palantir Foundry 2026 年 11 月公告（Ontology SQL GA：2026-11-12；Remote preview：2026-11-10）；Databricks：Announcing GA of Genie Ontology（2026-11-11）
