🤖 AI Agent 前沿洞察

Gemini API 推出 Tool Retrieval 预览：按需加载工具 schema

11 月 19 日，Google 宣布在 Gemini Interactions API 中以预览形式推出 Tool Retrieval。官方说明称：当 Agent 连接数十乃至上百个工具时，每次请求都发送完整参数 schema 会增加输入 token、延迟，并可能降低选工具的准确率。开启后，需在请求中加入 tool_search 工具，并对希望延后加载的工具设置 defer_loading: true；模型仍能看到全部延后工具的名称与描述，但参数 schema 先不进入上下文，需要时再在同一次请求内按名称加载并完成函数调用。该能力也可用于远端 MCP 服务器（对 mcp_server 工具设置同一标志即可按需加载其全部工具），并支持客户端检索（"execution": "client"）。官方称 Tool Retrieval 不单独计费，适用于 Gemini 3.6 及之后的模型（含全部 Gemini 4）。示例代码使用的是 gemini-4-hydrogen。

来源：Google 官方博文《Introducing Tool Retrieval in the Gemini API》（2026-11-19）

Mac 版 Gemini 应用上线计算机操作

同一天，Google 宣布在 Mac 版 Gemini 应用中引入 computer use：用户可用自然语言描述跨本地文件、桌面应用与网页的多步任务，由 Gemini 在隔离的后台窗口中点击、输入并操作菜单，主屏幕与光标保持空闲；用户可选择应用权限、观看实时预览，并在关键操作前批准。官方给出的起步场景包括批量调色、从本地 PDF 提取信息填写运单、从仪表盘拉取指标生成幻灯片等。该功能即日起以英语在美国推出，需搭载 Apple Silicon、运行 macOS Sequoia 15.0 或更高版本，面向 18 岁以上个人 Google 账号，并面向 Google AI Plus、Pro 与 Ultra 用户。TechCrunch 援引官方时写到，公司暂未说明向其他市场或平台扩展的时间表。

来源：Google 官方博文《Let Gemini tackle repetitive chores on your Mac》（2026-11-19）；TechCrunch（2026-11-19）

微软为 Foundry IQ 增加知识图谱与检索模型，用于 Agent 接地

11 月 19 日，InfoWorld 报道微软为 Foundry IQ 增加知识图谱能力，并推出检索模型 Microsoft-Retriever-1。报道写到：以往检索往往只能找到与问题相似的文档，难以自动沿「法规—供应商—产品」这类关系链追踪；知识图谱则让 Agent 自行沿链路查找并引用每一环。Retriever-1 被描述为可决定在何处查找、下一步问什么、以及何时已经收集足够证据。为简化部署，微软还计划在每个新建 Foundry 项目中自动配置托管的 Foundry IQ 资源，使开发者不必再单独开通 Azure AI Search；该托管服务预计于 2026 年 12 月进入公开预览，按用量的无服务器模式计费。报道同时转述分析师提醒：自动抽取可能误读行业术语或命名不一致，图谱答案也可能比常规检索更慢、更贵，更适合复杂查询而非日常查找。

技术突破Recursion 宣布 REC-4881 注册 III 期方案获 FDA 对齐，计划 2027 年下半年启动
