🤖 AI Agent 前沿洞察

亚马逊威胁情报：Cairn 自主 Agent 发现并利用 MONAI Label 零日漏洞

AWS Security Blog 于 11 月 20 日发布、由 CJ Moses 署名的调查指出：亚马逊威胁情报在 9 月 10 日发现一台未做身份验证、对外公开的 Cairn 实例。Cairn 是开源的自主渗透测试与问题求解框架。操作者向 Agent 提供目标 IP，并以自然语言给出「获得 shell 访问」一类目标，由多个 Agent 自行规划、执行并调整步骤。该活动约 48 小时，始于 9 月 8 日，目标为东亚、中国大陆以外的大学网络。亚马逊根据简体中文提示词、脚本时区为中国标准时间以及目标选择，以「中等置信度」评估操作者具有中国关联。

BleepingComputer 将受影响软件识别为开源医疗影像标注工具 MONAI Label。亚马逊称，Agent 在约 11 分钟内完成 API 测绘并发现上传参数中的路径遍历，从而向任意位置写文件；在后续会话中，它们把 Python 反向 shell 写入启动时会被导入的文件，再触发训练 API，使新进程以 root 权限回连。亚马逊以「高置信度」判断该漏洞在发现时为 zero-day。项目咨询于 11 月 18 日发布：受影响版本包含 0.8.5 及更早版本，咨询中未列出已修补发行版，并写明修复将进入下一版本；默认关闭身份验证时，任一可访问该服务器的网络客户端均可利用该缺陷。亚马逊称受影响机构不是 AWS 客户，已通过政府合作方联系对方。

并非所有行动都成功：针对一所大学未认证 Redis 的行动持续约 16 小时、148 个连续步骤后失败；针对 GPU 服务器的另一次行动超过 6 小时，Agent 从公开来源拼出约 80 个真实用户名并测试了 3 万余组凭据，仍未获得可用登录。

来源：AWS Security Blog（2026-11-20）；AI.info 综述（2026-11-22）

Shepherd：用「元 Agent」管理其他 Agent 的开源尝试

IEEE Spectrum 于 11 月 19 日报道，东北大学、斯坦福大学与加州大学伯克利分校的研究者（包括 Simon Yu、Derek Chong、Weiyan Shi 等）介绍了开源框架 Shepherd。它被描述为一个用于监督和管理其他 AI Agent 的「元 Agent」，借鉴软件开发中的版本控制思路，记录 Agent 的动作与状态，使一个 Agent 能够检查并操作另一个 Agent。文章强调：随着多 Agent 系统进入真实工作流，Agent 管理本身正在成为独立问题。
