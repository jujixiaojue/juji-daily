🤖 AI Agent 前沿洞察

Google DeepMind 发布 Gemini Robotics 2.5，并开源安全评测 ASIMOV-Jailbreak

11 月 10 日，DeepMind 发布视觉-语言-动作（VLA）模型 Gemini Robotics 2.5。官方称在约 200 项任务上评估（如夹取上菜、给礼盒系蝴蝶结、移液），相对此前基线成功率提升约 30%–100%，完成速度加快约 20%–30%；模型可适配多种机器人形态，包括 Apptronik Apollo 2 人形机器人与 Franka Duo。与 Apptronik、Mercedes-Benz 在匈牙利凯奇凯梅特和德国辛德芬根产线做概念验证：Apollo 2 执行汽车零件分拣入盒（kitting），官方公布成功率为 96%。安全方面，推理期引导使绕过障碍与近人作业的安全完成率分别提升约 33% 和 43%。同时开源越狱评测集 ASIMOV-Jailbreak；官方称 Gemini 4 Argon 在该集上的抵抗率为 99.5%，此前基线 Gemini Robotics ER 2 为 82%。周末仍有行业媒体跟进报道。

来源：Google DeepMind 官方博客（2026-11-10）；后续报道见 Ars Technica、Robotics and Automation News（2026-11-15）

Agent Skills 与 MCP 在 AAIF 下的共同维护持续被强调

Anthropic 于 10 月 22 日将 Agent Skills 规范捐赠给 Linux 基金会旗下的 Agentic AI Foundation（AAIF），与 MCP 一并纳入厂商中立治理。11 月 11 日，Google 开源博客刊出对 MCP / Agent Skills 核心维护者 Kurtis Van Gent 的访谈，称 Google、Anthropic、OpenAI 及更广泛生态正在共同维护该标准；文中回顾 2026 年 7 月 28 日 MCP 规范转向无状态、可水平扩展的传输模型。今日 GitHub 日榜上的 stitch-skills、SkillEvaluator 与 LoopForge，也从技能库、技能评测和带人工关卡的交付工作流三个方向，呼应同一套开放标准。

来源：Google Open Source Blog（2026-11-11）；Anthropic：Donating Agent Skills to the AAIF

KubeCon：Red Hat 加强 OpenShift / RHEL 上的 Agent 运维与安全

在本周举行的 KubeCon + CloudNativeCon NA 2026 上，Red Hat 发布围绕 OpenShift 5 与 RHEL 的更新，重点包括用 AI Agent 辅助集群排障与升级，以及为非确定性智能体提供密钥掩码、沙箱等安全层。行业报道将其概括为竞逐企业环境中的「Agent 空中交通管制」。具体功能边界与正式版本号请以 Red Hat 公告为准。

未来方向洞察：今天能看到三条并行的线索。一是标准层：MCP 与 Agent Skills 进入 AAIF 共同维护后，技能库、技能评测和带审批关卡的工作流开始一起出现在开源热榜上，说明「怎么给 Agent 注入可复用程序知识」正在从各家私有格式走向可移植资产。二是上下文层：企业不再满足于单 Agent、单域的临时提示词，而是把本体当作所有智能体共享的语义基础设施（详见下一板块的 Databricks Genie Ontology）。三是物理与治理层：Gemini Robotics 2.5 把 Agent 从屏幕推进到产线，同时用开源越狱评测约束长程动作；Red Hat 则在集群侧补运维和沙箱。对本体 / Agent 中台而言，选型重点正从「再做一个通用多 Agent 框架」转向：业务语义是否可治理、技能是否可评测、工具调用是否可降级，以及长程动作能否被审计。

二、企业知识本体 / 本体中台（与区块链 Ontology 不是同一件事）

Databricks 宣布 Genie Ontology 正式可用（GA，11 月 11 日）。官方将其定位为「由 Agent 构建、由人治理、供每个 Agent 使用」的企业级本体：智能体从仪表盘、SQL、笔记本、Power BI 等语义模型中持续学习，沉淀可复用的 Ontology Snippets；必须精确的定义（如确认收入、ARR）则由人通过 Unity Catalog 的 Metric Views、Domains 与 Pages 建模，并作为权威来源。OntoRank 按来源权威性、认证、人员相关性、流行度与新旧程度对冲突定义排序。通过 Genie MCP，同一套上下文也可提供给 ChatGPT、Claude、Microsoft Copilot 等外部智能体。官方称已有数千家客户在生产中运行 Genie Agents，点名客户包括 7-Eleven、Virgin Atlantic 与 General Motors。

同期发布的、与 Turing 合作的可分享基准称：在模拟英国能源公司的真实 Databricks 工作区中，带 Genie Ontology 的 Genie 通过率为 91%，对照的两个前沿 Agent 分别为 45% 与 58%，即约 1.6 倍通过率，同时消耗不到一半的 token，完成时间快 3–4 倍。该基准包含笔记本、仪表盘、已保存 SQL 和文档，而不仅是表结构。上述数字来自 Databricks 与合作方公布的评测，并非独立第三方复现。待核实

来源：Databricks：Announcing GA of Genie Ontology；配套评测博文

💊 AI 制药板块

下文区分「AI 辅助研发 / AI 发现与设计」与「已进入人体的在研管线 / 已上市药物」。目前公开信息里，多数成果仍在临床前或早期临床，尚不能等同于已上市药物。

a) 融资与并购

  • Orakl Oncology（法国，11 月 12 日）：这家 2023 年成立、源自 Gustave Roussy 的 TechBio 公司完成 3,400 万美元 A 轮，由 Norrsken VC 与 Singular 联合领投，InfraVia Growth、Bpifrance 的 Patient Autonome Fund 等参与，累计融资约 5,000 万美元。公司把 AI 模型与实验室培养的患者肿瘤、临床史连接，用于在人体试验前预测抗癌药物试验结局；「约 90% 预测准确率」为公司自行披露，尚未见到独立复现。待核实 这属于试验结局预测 / AI 辅助研发工具，不是已上市药物。来源：Orakl / InfraVia 新闻稿（2026-11-12）；HIT Consultant。
  • nPhase（美国，11 月 2 日宣布，中文媒体 11 月 15 日仍在跟进）：AI 原生临床数据平台完成 3,000 万美元 D 轮，由 Viking Global Investors 领投。报道称这是公司自 2017 年以来首次股权融资，技术源于范德堡大学 REDCap。定位是临床数据管理与 agentic 工作流，而非药物分子设计。来源：Fierce Biotech；摩熵医药 / 智药邦（2026-11-15）。

b) 管线、合作与临床相关进展

  • 翰森制药 × 昂心生物（AilsynBio，11 月 13 日）：翰森制药（03692.HK）公告，全资附属翰森（上海）健康科技与昂心生物订立合作开发协议，获得使用对方 AI 平台发现新型口服环肽候选药物的许可；翰森有权选择靶点、取得项目知识产权并主导后续开发，昂心生物最高可收取人民币 3.17 亿元，另加已获批产品的个位数销售分成。这属于 AI 发现 / 设计候选分子的授权合作，目前尚未见到具体进入人体的管线披露，更不是已上市药物。来源：香港交易所公告（2026-11-13）；新时空。
  • UCB × Cradle（11 月 3–4 日宣布，11 月 14 日行业综述仍在转载）：比利时药企 UCB 将 Cradle 的端到端 AI 蛋白质设计平台纳入其数字化抗体工程项目，覆盖从命中生成到工程优化的选定发现项目。这是 AI 辅助 / 从头设计抗体候选物的平台型合作，不是已上市药物；财务条款公开报道中未见完整披露。来源：UCB 官方新闻稿；Bio-IT World（2026-11-14）。
  • Lab Thread 推出实验室 MCP 服务（见于 11 月 14 日行业综述）：科学家可将自有助手（如 ChatGPT、Claude）经 MCP 连接到实验室结构化记录，官方强调租户隔离、角色权限与不可篡改审计日志，只向模型发送必要上下文。这属于湿实验数据接入 Agent 的产业工具，并非药物本身。来源：Bio-IT World。

c) 政策与监管

11 月 13 日，国家药监局药品审评中心（CDE）网站公开征求《药物临床试验申办者变更有关问题问与答（征求意见稿）》意见，明确临床试验期间申办者变更的申报路径：变更后的申办者承担相关责任和义务，并应按规定向药品监督管理部门提出申请。该文件面向一般药物临床试验，并非专门针对 AI 制药，但对涉及申办者变更的合作与管线交易有直接影响。

来源：中国食品药品网（2026-11-14，转述 CDE 11 月 13 日通知）；征求意见稿 PDF：问与答（征求意见稿）

d) 产业讨论：实验室自主性需要人在环内

11 月 13 日前后，《Frontiers in Robotics and AI》一项对英美德实验化学家的访谈研究指出，受访者欢迎机器人承担重复的样品准备与筛选，但反对完全自主实验室；《Frontiers in Genetics》一篇观点文章则建议，基因组学中的多 Agent 系统应预先限定权限、落实机器可读的知情同意，并在对外传输等关键节点要求人工签核。上述研究样本有限，是学术观点而非新的监管规则。

来源：转述见 AI for Science Brief（2026-11-13）
